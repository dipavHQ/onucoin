OnuWorlds Codex

Two axes. Four world-states. One mistake: confusing LUNA with VAPID. LUNA is upward delusion. VAPID is horizontal emptiness. They require different reversals.

1 · Definition

What a World-State Is

An OnuWorld is a reality condition: the dominant logic governing attention, ambition, and meaning. It is not a mood. It is an operating environment.

World-states describe where you are living.
Spins describe how your internal system is currently configured.
HOBO is a collapse pattern that appears when the system breaks.

2 · Axes

The Two Axes of Failure

The canon is built on two paired reversals:

  • Fantasy Axis: LUNA → ANUL
  • Culture Axis: VAPID → DIPAV

LUNA and VAPID are not the same problem. Treating them as one is the default error.

3 · The Four

The Four World-States

LUNA

The fantasy world. Upward delusion. “To the moon” logic: transcendence promised, structure deferred. LUNA feels alive because it is powered by projection.

  • Orientation: up
  • Core error: projection mistaken for progress
  • Common symptom: destiny talk with no structure

ANUL

The annulment state. LUNA invalidated. Not escape — cancellation of authority. Moon Blast is the OnuBlast-class event that produces ANUL.

  • Orientation: down to reality
  • Core effect: fantasy loses jurisdiction
  • Common symptom: “the spell breaks”

VAPID

The default world. Horizontal emptiness. Noise, performance, stimulation without meaning. VAPID feels normal because it is everywhere.

  • Orientation: flat
  • Core error: motion mistaken for meaning
  • Common symptom: exhaustion without direction

DIPAV

Vapid reversed. The re-authored world. Structure with meaning. Silence with authority. Entry requirement: TO THE CORE.

  • Orientation: inward
  • Core effect: meaning regains control
  • Common symptom: fewer moves, higher consequence
4 · Pattern

HOBO Is Not a World

HOBO (Hollow Order → Broken Order) is a collapse pattern, not a world-state. It appears when a system can no longer sustain the demands placed on it.

HOBO most commonly emerges when:

  • LUNA fantasies crash into reality, or
  • VAPID performance continues past capacity, or
  • spin misalignment is prolonged (Cooldown or Void denied).

HOBO is the crack where truth becomes unavoidable. Dipav is what you build after the crack.

Closure

One Line That Prevents Confusion

LUNA promises escape without depth.
VAPID delivers motion without meaning.
DIPAV goes TO THE CORE.
